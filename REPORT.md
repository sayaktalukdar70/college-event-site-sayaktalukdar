# College Event Management Website: Project Report
**Name / Roll No.:** ______  **Course:** PCCCS382 IT Workshop  **Dept:** CSE (AIML), IEM Kolkata

## 1. Objective
Build a responsive, single-page website for department events using HTML5, CSS3 and JavaScript, with event listing, registration with validation, gallery, about and contact sections.

## 2. Folder structure
index.html (structure) · css/style.css (presentation) · js/script.js (behaviour) · images/ · screenshots/ · REPORT.md

## 3. Sections
Home (logo, nav, intro, countdown) · Events (6, from a JS array) · Register (7 fields, validated) · Gallery (6 images, hover) · About us (coordinators) · Contact (address, mailto/tel, feedback form)

## 4. JavaScript features
Form validation (regex) · event countdown · IST digital clock · dark/light mode (localStorage) · event filtering · mobile menu with current-section highlight

## 5. Responsive approach
CSS Grid and Flexbox, viewport meta tag, clamp() fluid sizes, media queries at 900 px (tablet) and 680 px (mobile, hamburger menu).

## 6. Testing
Tested on desktop, tablet and phone widths; empty form submit; invalid and valid inputs; every nav link; dark mode reload; HTML validated at validator.w3.org.

## 7. Limitations
No back end: registrations and feedback are validated but not stored. Gallery uses placeholder images; replace with real event photos.
